# Poké City (play page)

A small private fan game made for a kid: collect Pokémon, give each a home in your town, watch them live there.
Built with [Rive](https://rive.app). This repo only hosts the playable page; progress is kept in your browser.
Add `?reset=1` to the address to start a fresh town.
